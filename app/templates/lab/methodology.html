Access Control Audit — Technical VM Lab Methodology

Authoritative documentation of the defensive laboratory environment, virtualization setup, security assessment tools, and ethical testing boundaries established for student Khadija Bukar (FE/26/4554984566).

Ethical Testing & Authorization Notice

All security assessments and packet analyses documented in this project were conducted strictly inside an isolated virtual network environment using VirtualBox VMs. Testing targeted only student-owned systems and intentionally vulnerable lab targets.

1. Laboratory Virtualization Architecture

The lab was constructed using Oracle VirtualBox operating on a host system running host-only and internal virtual network switches (`192.168.56.0/24`).

2. Toolchain Execution Methodology

Nmap NSE scripts were executed to audit open administrative services, SMB share permissions, and unauthenticated RPC endpoints. 
# Nmap Script Scan for Exposed Shares & Administrative Ports
nmap -sV -sC --script=smb-enum-shares,smb-enum-users 192.168.56.20 -oX nmap_service_permission_audit.xml

Wireshark was used to capture network traffic during user login and API invocation, verifying that authorization headers and session tokens are transmitted securely over HTTPS and not leaked in plaintext.

OWASP ZAP Access Control Testing Add-on was executed to test for horizontal and vertical privilege escalation vectors across all endpoints.
